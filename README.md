# Action Palette for Gmail

**Every Gmail action, one keystroke.** A command palette for Gmail — press
`Cmd/Ctrl + Shift + P`, fuzzy-search any action, and run it from the keyboard.
Archive, label, snooze, reply, jump to any folder, and compose without touching
the mouse. A fast, private, lightweight alternative to heavyweight email clients.

🌐 **Website:** https://mpartipilo.github.io/gmallet-project/
💬 **Feedback & bug reports:** [open an issue](https://github.com/mpartipilo/gmallet-project/issues)

> This repository is the project's public home — landing page, marketing, and
> issue tracker. The extension's source code is not published here.

## Why

Power users live on the keyboard. Gmail has shortcuts, but you have to memorize
them. Action Palette gives you the VS Code experience: open the palette, type a
few letters, hit Enter. Discoverable, fast, and it teaches you the native
shortcuts as you go.

## Features

- **Command palette** with fuzzy search over every action.
- **Keyboard-first triage** — archive, delete, mark read/unread, snooze, star,
  mark important, mute, label, move, report spam, add to Tasks.
- **Navigation** — jump to Inbox, Starred, Sent, Drafts, any label, or the
  category tabs, all from the palette.
- **Reply / Reply-all / Forward** from an open conversation.
- **Context-aware** — only applicable actions are offered for the current view.
- **Works in the standalone message popout window**, not just the main tab.
- **Localized** — follows your Gmail language (English & Spanish shipped, more
  to come; falls back gracefully for other languages).

## Privacy

Privacy is a core design goal, not an afterthought:

- The extension requests access to **`mail.google.com` only**.
- It does **not** read, store, or transmit the contents of your email.
- The free core runs **entirely locally** — no servers, no tracking, no network
  calls. (The optional paid tier validates a license key, and only that.)
